# Go Pet Shop

---
## Описание:
Проект, созданный на основе уже существующего [Go pet shop](https://github.com/pavloging/go-pet-shop).
Добавлены новые возможности REST API, работа с PostgreSQL, транзакционная обработка заказов, валидация и обработка ошибок, тестирование и аналитические запросы.

Разработка выполнена в четырёх версиях (v1–v4), каждая из которых добавляет отдельную часть функциональности поверх исходного проекта.

## Версии проекта:
### `v1` — Работа с товарами и пользователями

Реализована базовая работа с пользователями и товарами.

Добавлены:
* создание и получение пользователей;
* получение пользователя по email;
* CRUD-операции для товаров;
* соответствующие REST API endpoints.

### `v2` — Заказы и позиции заказа
Добавлена работа с заказами и позициями заказа.

Добавлены:
* создание заказа;
* добавление товаров в заказ;
* получение деталей заказа;
* получение заказов пользователя;
* SQL-запросы с JOIN для работы со связанными сущностями.

### `v3` — Оформление заказа с транзакцией
Реализовано полноценное оформление заказа с использованием PostgreSQL-транзакции.

Во время оформления заказа:

* проверяется наличие товаров на складе;
* обновляется количество товара (stock);
* создаётся заказ;
* создаются позиции заказа;
* создаётся запись о финансовой транзакции;
* все операции выполняются атомарно с использованием COMMIT / ROLLBACK.

### `v4` — История заказов и аналитика
Добавлены возможности просмотра истории заказов и анализа продаж.

Добавлены:

* получение полной истории заказов и связанных транзакций пользователя по email;
* SQL-запросы с несколькими JOIN для объединения данных о пользователях, заказах, товарах и транзакциях;
* получение популярных товаров;
* аналитический запрос с GROUP BY и агрегатной функцией SUM для подсчёта количества проданных товаров.

## Запуск проекта
1. Клонировать репозиторий:
```
git clone https://github.com/Nonlight/go-pet-shop.git
```
2. Перейти в директорию проекта:
```
cd go-pet-shop
```
3. Скопировать файл-шаблон .env.example:
```
cp .env.example .env
```
4. Запустить контейнеры:
```
docker compose up -d
```
5. Применить миграции:
```
task migrate
```
После запуска сервис доступен по адресу `http://localhost:8080`.

## Тесты
В проекте реализованы:

* unit-тесты для HTTP-handlers с использованием моков;
* интеграционный тест оформления заказа order_integration_test.go.

Для запуска всех тестов:

`go test ./...`

Для запуска интеграционных тестов PostgreSQL необходимо запустить базу данных:

`docker compose up`
